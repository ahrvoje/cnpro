ControlNet Pro for Forge Neo

Worked examples

A ControlNet usually reaches you as one weight slider. CNPro opens the three axes it was always acting on — steps, depth and space — and these pages show what that buys, one setting at a time, with the unit panel exactly as it was set for each shot.

Every example is reproducible: same checkpoint, same seed, every profile string written out, and each step is one picture that answers one question. Nothing below is a mock-up — the screenshots are the real widget, and every image was generated by the configuration shown next to it.

What these pages assume

Forge Neo with the CNPro extension installed and the built-in sd_forge_controlnet disabled. The pictures were made on thisisrealSDXL_v30 with sdxlVAE, DPM++ 2M Karras, 30 steps, CFG 5, 1024×1024 — but nothing in the reasoning depends on that checkpoint. The reference images are themselves generated by the same model, so there are no external assets to download and nothing to attribute.

If you only read one thing, read the depth-axis section of example 1. Every other trick in CNPro is easier once you can see the model as a stack of injection sites rather than a single knob.
